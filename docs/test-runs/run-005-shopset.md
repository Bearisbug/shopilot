## 环境问题

1. 模拟授权页在 Shopilot 拒收的授权里（`auth-link-6min` 的过期 state、子账号授权）仍把店铺记成「已授权」并按点击时刻重算到期时间；之后跑 `token.refresh` 时 Shopilot 会取回这个新到期时间。不影响本组结论，但 `TC-SHOP-010` 第 3 步要在下一次 `token.refresh` 之前读才与前置逐字相同。
2. 多个用例共用 Partner ID 2001001，每个新商户校验后回调都改指向自己的应用；`TC-SHOP-015` 第 2 步把回调改到 `/mock/erp/...` 后，后续新商户校验 2001001 会先得到 409 `/errors/callback-occupied`。本组在 `TC-SHOP-003` 前按 §3「Shopee 改回调」把回调改回一个 Shopilot 回调地址后继续（见该行备注）；建议在 §5 写明这组用例的执行顺序，或给 `TC-SHOP-015` 加「把回调改回」的后置。
3. 故障注入清除要 `PUT /api/mock/sim/faults` 带 `mode: off`，`DELETE` 不生效（静默返回）。
