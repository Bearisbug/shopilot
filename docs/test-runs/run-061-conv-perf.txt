环境：本机 next build + next start（生产构建，端口 3381）+ Worker，独立库 shopilot_wt_convperf，Edge headless 1440×900；
CDP 模拟慢网：延迟 150 ms、下行 1.5 Mbps、上行 750 kbps。登录 owner@demo.test，打开 /wb?view=queue，停留 2.5 秒后依次点列表前 8 行。
为凑满 8 行，库里另把 2 个会话改成待认领，并给部分会话补了消息；改前、改后用同一份数据。
两种点法：悬停 = 指针移到行上停 300 ms 再点；直接点 = 指针移到行上立即点（Playwright click）。每种 8 个会话 × 3 轮 = 24 次，取中位数，单位 ms。
「会话头」= 对话栏出现被点会话的买家名（改后是占位会话头，读屏名「正在打开与 X 的会话」）；「内容就绪」= 出现真实会话 section「与 X 的会话」。
「详情返回」= GET /api/v1/conversations/<id> 从点击到返回；悬停预取命中缓存时点击后没有这条请求。
