# Shopilot 商户内角色与权限

2026-10-11 用户定：商户内分三种角色——管理员、组长、员工。「账号所有者」是某一位管理员身上的属性，不是第四种角色。原型和实现都按本表做权限；`/team/permissions` 展示的就是这张表。

## 角色

| 角色 | 谁 | 能看到的范围 |
| --- | --- | --- |
| 管理员 | 商户负责人、运营主管 | 全部店铺 |
| 组长 | 某几家店的客服组长（一位组长可负责多家店） | 负责店铺内的全部会话、工单、订单 |
| 员工 | 一线客服 | 负责店铺的待认领会话、自己处理中的会话、指派给自己的工单 |

账号所有者：注册商户的那位管理员。只有所有者能改套餐、改付款方式、转让所有权、删除商户；所有者不能被移除或降级，要先转让所有权。

## 侧栏可见项

| 侧栏项 | 管理员 | 组长 | 员工 |
| --- | --- | --- | --- |
| 工作台、工单、订单与开票、知识库 | ✓ | ✓ | ✓ |
| 看板 | ✓ | ✓ | — |
| 接待设置、店铺与连接、团队与权限、用量与套餐、商户设置 | ✓ | — | — |

员工在知识库里只看到「资料与经验卡」「AI 测试」两个标签；「更新审核」「AI 核验」只对管理员和组长显示。

## 原型里怎么切换身份

账号弹层 `/account` 里有「预览身份」：管理员（林晓，同时是账号所有者）、组长（Arif Rahman，负责 MY 站 2 家）、员工（Nur Aisyah，负责 Shopee MY）。切换后侧栏、按钮按上表隐藏，进入无权页面时显示「这个页面只对 X 开放」。这是原型的预览手段，上线后身份取自登录账号。

原型里的约定（`design/quilt/kit.py`）：

- 只有部分角色能用的按钮或区块带 `data-roles="admin lead"`，运行时按当前身份隐藏。
- 整页受限的屏用 `shell(body, action, roles="admin")`，运行时显示无权提示。
- 侧栏按 `NAV_HIDE` 隐藏导航项。
